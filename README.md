# Fashion-Shop-Website
A modern full-stack Fashion Shop e-commerce website built with React and FastAPI, featuring product browsing, categories, search, user authentication, shopping cart, and AI-powered product image generation.

# 🛍️ Fashion Shop Website

A modern, responsive, full-stack e-commerce platform designed to provide a seamless and enjoyable online fashion shopping experience.

## 🚀 Features

- Modern and responsive user interface
- Product listing and product details
- Category-based product filtering
- Product search functionality
- User registration and login
- Secure authentication
- Shopping cart functionality
- Product management
- Backend REST API integration
- Database connectivity
- AI-powered product image generation
- Cloud image storage integration

## ⚙️ Installation & Setup

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Fashion-Shop-Website.git
```

### 2. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 3. Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

## 🌐 Application URLs

- Frontend: http://localhost:5173
- Backend API: http://127.0.0.1:8000
